# Ustam Oto PWA

Ustam Oto, iPhone'da Safari üzerinden açılıp Ana Ekrana Eklenebilen lokal randevu uygulamasıdır.

## Özellikler
- Bugün / Takvim / Randevular
- Tarih, saat, müşteri, telefon, araç ve servis notu
- Arama
- Düzenleme / silme
- Veriler cihazın localStorage alanında tutulur; sunucu gerekmez.
- PWA standalone modu ve offline cache

## Yayınlama
PWA'nın iPhone'da kurulabilmesi için HTTPS üzerinden yayınlanması gerekir. GitHub Pages, Netlify veya Cloudflare Pages kullanılabilir.
